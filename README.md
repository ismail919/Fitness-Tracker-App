# FitFab – Android Fitness Tracker

A native Android fitness tracking application developed as my **BSc (Hons) Computer Science final-year project** at Leeds Beckett University.

## Overview

FitFab is an Android application designed to help users monitor their fitness activity using data collected from their mobile device.

The application uses Android device sensors to collect movement data and stores fitness information locally for users to view and track.

## Technologies

- **Kotlin**
- **Android Studio**
- **Android SDK**
- **MVVM Architecture**
- **Room Database**
- **SQLite**
- **SensorManager API**
- **Git & GitHub**

## Key Features

- Fitness activity tracking using device sensors
- Real-time movement data collection
- Local storage using Room and SQLite
- Fitness activity history
- MVVM architecture
- User-friendly Android interface

## Architecture

The application follows the **MVVM (Model-View-ViewModel)** architecture to separate the user interface, application logic and data layers.

**Room/SQLite** is used for local data persistence, while Android's **SensorManager API** is used to access movement-related sensor data.
